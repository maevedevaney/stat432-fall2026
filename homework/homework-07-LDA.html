Study design

  • Reserved a stratified 20% test set before model selection.
  • Used the remaining 80% for model comparison.
  • Within the training data, applied the same 5-fold cross-validation splits to all candidate models.
  • For PCA-based candidates, preprocessing was fit only on the training observations in each fold.
  • Candidate set: ordinary LDA and PCA-LDA with 2–9 principal components after standardization.

Selected model and final result

The best cross-validated performer was PCA-LDA with 7 components, using a standardization step followed by an embedding estimated only on the training data in each fold. After refitting the selected preprocessing and model on the full training set, the final test misclassification rate was 0.2366.

Interpretation

  • The PCA-based embedding modestly improved predictive performance relative to ordinary LDA.
  • The gain on the held-out test set was small but consistent with the cross-validation comparison.
  • The dataset is modest in size and somewhat imbalanced, so the improvement should be interpreted cautiously.
  • A limitation is that the comparison is based on a single random train/test split; different splits may change the ranking slightly.

Main finding

Within the LDA-based model family allowed here, a low-dimensional PCA embedding improved the classification error over ordinary LDA on the reserved test set, with the best model being PCA-LDA using 7 components.
