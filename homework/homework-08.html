Question 1: Boundary and margin

Use margin-geometry-20.csv from the combined ZIP, which contains 20 observations with predictors x1,x2x_1,x_2 and class labels y∈{−1,1}y\in\{-1,1\}. Consider the score

f(x)=0.8x1+0.6x2. f(x)=0.8x_1+0.6x_2.

Since ∥(0.8,0.6)∥2=1\|(0.8,0.6)\|_2=1, the lines f(x)=±1f(x)=\pm1 are each a distance 1 from the decision boundary f(x)=0f(x)=0.

  1. Calculate the distance from every observation to the decision boundary and its functional margin yf(x)yf(x). In a table, report these values and whether each observation is inside, on, or beyond the margin for its class. Compare yf(x)yf(x) with 1 to make this distinction.

  2. Plot the observations, the boundary f(x)=0f(x)=0, and the margin lines f(x)=±1f(x)=\pm1. Distinguish the two classes and identify the observations inside the margin in your plot.

  3. Report how many observations are inside, on, and beyond the margin. Which observations are misclassified by this decision rule?

Use the observation numbers supplied in the data. Set the x1x_1 axis to [−3.2,3.2][-3.2,3.2], set the x2x_2 axis to [−3,3][-3,3], and use an equal aspect ratio. Do not fit a new classifier for this question.

Question 1(a) Solution

The score is f(xi)=0.8xi1+0.6xi2f(x_i)=0.8x_{i1}+0.6x_{i2}. Because ∥(0.8,0.6)∥2=1\|(0.8,0.6)\|_2=1, the distance to the boundary is |f(xi)||f(x_i)|, and the functional margin is yif(xi)y_if(x_i). An observation is inside its class margin if yif(xi)<1y_if(x_i)<1, on it if yif(xi)=1y_if(x_i)=1, and beyond it if yif(xi)>1y_if(x_i)>1.

q1 <- read.csv("data/margin-geometry-20.csv")
q1$score <- 0.8 * q1$x1 + 0.6 * q1$x2
q1$distance <- abs(q1$score)
q1$functional_margin <- q1$y * q1$score
# Round only when comparing with 1 to avoid floating-point equality issues.
q1$status <- ifelse(round(q1$functional_margin, 8) < 1, "Inside",
                    ifelse(round(q1$functional_margin, 8) == 1, "On", "Beyond"))
knitr::kable(

Question 2: Margin in four dimensions

Use margin-geometry-4d.csv from the combined ZIP, which contains 50 observations with four predictors and class labels y∈{−1,1}y\in\{-1,1\}. Consider the linear score

f(𝒙)=β0+𝒙𝖳𝜷,β0=−1,𝜷=(1,2,−2,4)𝖳. f(\mathbf{x})=\beta_0+\mathbf{x}^{\mathsf T}\boldsymbol{\beta}, \qquad \beta_0=-1, \quad \boldsymbol{\beta}=(1,2,-2,4)^{\mathsf T}.

  1. Project the observations onto the direction of 𝜷\boldsymbol{\beta} and plot their positions on one axis. Distinguish the two classes and mark the decision boundary. Use the plot to calculate the geometric margin MM, the distance from the boundary to the closest observation.

  2. Express the same decision boundary using the SVM normalization in which the smallest functional margin yif(𝒙i)y_i f(\mathbf{x}_i) is set to 1. What are the corresponding values of 𝜷\boldsymbol{\beta} and β0\beta_0?

Question 2(a) Solution

The coefficient vector is 𝜷=(1,2,−2,4)𝖳\boldsymbol{\beta}=(1,2,-2,4)^{\mathsf T}, with length

∥𝜷∥2=12+22+(−2)2+42=5. \|\boldsymbol{\beta}\|_2=\sqrt{1^2+2^2+(-2)^2+4^2}=5.

Project each observation onto its unit direction using zi=𝒙i𝖳𝜷/5z_i=\mathbf{x}_i^{\mathsf T}\boldsymbol{\beta}/5. Because the intercept is −1-1, the boundary is at z=1/5=0.2z=1/5=0.2.

q2 <- read.csv("data/margin-geometry-4d.csv")
q2$score <- -1 + q2$x1 + 2*q2$x2 - 2*q2$x3 + 4*q2$x4
q2$projection <- (q2$score + 1) / 5
q2$distance <- abs(q2$score) / 5
q2$functional_margin <- q2$y * q2$score
closest <- abs(q2$distance - min(q2$distance)) < 1e-8
plot(q2$projection, rep(0, nrow(q2)), type = "n", yaxt = "n", ylab = "",
     xlab = "Projection onto beta / ||beta||", ylim = c(-0.5, 0.5),
     main = "Four-dimensional observations projected onto one axis")
abline(v = 0.2, lwd = 2)
points(q2$projection, rep(0, nrow(q2)),
       col = ifelse(q2$y == 1, "steelblue", "tomato3"), pch = 19)
points(q2$projection[closest], rep(0, sum(closest)), pch = 21,
       bg = NA, cex = 2, lwd = 1.5)

     labels = q2$observation[closest], pos = 3, cex = 0.85)

       col = c("steelblue", "tomato3", "black", "black"),

The closest observations are 4, 15, 33, and 36, with scores 5,−5,5,−55,-5,5,-5, respectively. Each is distance 5/5=15/5=1 from the boundary, so the geometric margin is M=1M=1.

Question 2(b) Solution

The smallest functional margin is min⁡iyif(𝒙i)=5\min_i y_if(\mathbf{x}_i)=5. Dividing the intercept and every coefficient by 5 preserves the boundary while making the smallest functional margin 1:

𝜷new=(0.2,0.4,−0.4,0.8)𝖳,β0,new=−0.2. \boxed{\boldsymbol{\beta}_{\mathrm{new}}=(0.2,0.4,-0.4,0.8)^{\mathsf T},\qquad \beta_{0,\mathrm{new}}=-0.2.}

The normalized score is fnew(𝒙)=−0.2+0.2x1+0.4x2−0.4x3+0.8x4f_{\mathrm{new}}(\mathbf{x})=-0.2+0.2x_1+0.4x_2-0.4x_3+0.8x_4.

min(q2$functional_margin)
min(q2$functional_margin / 5) # Equals 1 after normalization
