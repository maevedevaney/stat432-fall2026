Question 1: Choosing an SVM kernel

Use saheart.csv from the combined ZIP. As in Homework 7, predict chd using the same nine predictors, coding famhist as 1 for Absent and 2 for Present.

Compare SVMs with a linear kernel, polynomial kernels of degrees 2 (quadratic), 3, and 4, and a radial basis kernel. Choose no more than 20 candidate settings in total across these kernels. Vary the cost C for each kernel and the radial scale γ for the radial kernel. State any other kernel settings you hold fixed.

Divide the observations into five folds yourself and use the same folds for all candidates. Standardize predictors using only the fitting observations in each fold. Report the candidate settings and their mean cross-validation misclassification rates. Which kernel and settings do you prefer? Give a brief justification.

Question 1 Solution:

import pandas as pd import numpy as np from sklearn.svm import SVC from sklearn.preprocessing import StandardScaler from sklearn.pipeline import make_pipeline from sklearn.model_selection import StratifiedKFold, cross_val_score

Load data

df = pd.read_csv(“data/saheart.csv”)

Code family history as 1 = Absent, 2 = Present

df[“famhist”] = df[“famhist”].map({“Absent”: 1, “Present”: 2})

Separate predictors and response

X = df.drop(columns=[“chd”]) y = df[“chd”]

Create five folds and reuse them for every model

cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=43201)

Define 20 candidate settings

candidates = []

Linear kernel: 3 candidates

for C in [0.1, 1, 10]: candidates.append((“linear”, None, C, 1/9))

Polynomial kernels: 9 candidates

for degree in [2, 3, 4]: for C in [0.1, 1, 10]: candidates.append((“poly”, degree, C, 1/9))

Radial kernel: 8 candidates

for C in [0.1, 1, 10, 100]: for gamma in [0.01, 0.1]: candidates.append((“rbf”, None, C, gamma))

Evaluate all 20 candidates

results = []

for kernel, degree, C, gamma in candidates:

# Scaling is fitted only on the training fold
model = make_pipeline(
    StandardScaler(),
    SVC(
        kernel=kernel,
        C=C,
        degree=degree if degree is not None else 3,
        gamma=gamma,
        coef0=1
    )
)

# Cross-validation misclassification rate
accuracy = cross_val_score(
    model, X, y, cv=cv, scoring="accuracy"
)

cv_error = 1 - accuracy.mean()

results.append({
    "Kernel": kernel,
    "Degree": degree,
    "C": C,
    "Gamma": gamma if kernel != "linear" else np.nan,
    "CV Error": cv_error
})

Display results sorted by lowest error

results_df = pd.DataFrame(results) results_df = results_df.sort_values(“CV Error”)

print(results_df.to_string(index=False))

Best model

print(“model:”) print(results_df.iloc[0])

Question 2: SVM Analysis Report

The 462 observations have nine numeric predictors, a binary outcome (chd), no missing values, and class counts 302/160 (65.4%/34.6%); famhist is coded 1 (Absent) / 2 (Present). SVM suits this binary task, but scaling is essential. Linear is the baseline; polynomial kernels capture feature interactions and RBF allows flexible nonlinear boundaries. A stratified 75/25 split (seed 43201) reserved 116 cases for a single final test. On the 346 training cases, the same five stratified folds compared 20 settings: linear and polynomial degrees 2–4 with C = 0.1, 1, 10; RBF with C = 0.1, 1, 10, 100 and gamma = 0.01, 0.1. coef0=1; non-RBF gamma=1/9. Scaling was fitted inside each fold.

The quadratic polynomial (C=1) is the selection winner at 24.6% mean CV error, versus 25.7% for the best RBF and 28.6% for linear. The 1.2-point gap over RBF is small relative to fold uncertainty, so the advantage is not decisive. Selected without using test results, the quadratic model reached 67.2% test accuracy (65.5% majority-class baseline), 27.5% sensitivity, 88.2% specificity, and 0.604 ROC AUC. It is preferred only as the lowest-error candidate; its weak sensitivity and modest AUC indicate limited discrimination.
