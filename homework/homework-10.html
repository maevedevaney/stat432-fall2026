Question 1: Bias-variance trade-off simulation

Two important tuning parameters of random forests are node size and mtry. We have performed some preliminary analysis in class. The goal of this question is to perform a larger simulation study for these two tuning parameters.

Consider a regression model with five jointly normally distributed predictors. Each predictor has mean 0 and variance 1, and the correlation between any two different predictors is 0.3. The response is

Y=X1+X3+X5+ε,ε∼N(0,1), Y=X_1+X_3+X_5+\varepsilon, \qquad \varepsilon\sim N(0,1),

where the noise is independent of the predictors. Thus the true regression function is f(𝒙)=x1+x3+x5f(\mathbf{x})=x_1+x_3+x_5.

  1. Set up a simulation study with 100 repetitions. Generate 200 test predictor vectors once and keep them fixed. In each repetition, generate 200 new training observations and use the same training data for all tuning settings. Fit 500-tree forests, drawing 200 observations with replacement for each tree. Make the following two comparisons:

    • Fix mtry at 3 and vary node size over 1,5,10,20,301,5,10,20,30.
    • Fix node size at 10 and vary mtry over 1,2,3,4,51,2,3,4,5.

    Leave all other fitting parameters at their defaults. Record the predictions at each test point across repetitions. For each setting, estimate the squared bias and variance at each test point, then average them over the 200 test points. Compare predictions with f(𝒙)f(\mathbf{x}) when estimating bias. Produce two figures, one for each tuning parameter, showing the averaged squared bias and variance. Set a random seed and report it.

  2. Discuss your results in terms of the bias-variance trade-off:

    • How does a large node size, such as 30, affect the fit in this example?
    • What are the benefits and drawbacks of using a large mtry value?
    • If each tree instead sampled 100 observations with replacement, would you expect the preferred node size to shift toward smaller or larger values? Explain your reasoning. You may use an additional simulation to help, but a particular pattern is not guaranteed.

Question 1 Solution

import numpy as np import pandas as pd import matplotlib.pyplot as plt from rlt import RLT

SEED = 432 rng = np.random.default_rng(SEED)

n_train = 200 n_test = 200 n_rep = 100 p = 5

Sigma = np.full((p, p), 0.3) np.fill_diagonal(Sigma, 1.0)

def true_f(X): return X[:, 0] + X[:, 2] + X[:, 4]

X_test = rng.multivariate_normal( np.zeros(p), Sigma, size=n_test ) f_test = true_f(X_test)

settings = ( [(“Node size”, n, 3) for n in [1, 5, 10, 20, 30]] + [(“mtry”, 10, m) for m in [1, 2, 3, 4, 5]] )

predictions = np.zeros((len(settings), n_rep, n_test))

for r in range(n_rep): X_train = rng.multivariate_normal( np.zeros(p), Sigma, size=n_train ) y_train = true_f(X_train) + rng.normal(size=n_train)

for j, (comparison, node_size, mtry) in enumerate(settings):
    model = RLT(
        model="regression",
        ntrees=500,
        mtry=mtry,
        min_samples_leaf=node_size,
        sample_fraction=1.0,
        replacement=True,
        reinforcement=False,
        random_state=SEED + r * len(settings) + j
    )
    model.fit(X_train, y_train)
    predictions[j, r, :] = model.predict(X_test)

results = []

for j, (comparison, node_size, mtry) in enumerate(settings): P = predictions[j] mean_pred = P.mean(axis=0)

bias2 = np.mean((mean_pred - f_test)**2)
variance = np.mean(P.var(axis=0, ddof=1))

results.append({
    "Comparison": comparison,
    "Node size": node_size,
    "mtry": mtry,
    "Squared bias": bias2,
    "Variance": variance
})

results = pd.DataFrame(results) print(results.round(4))

for comparison, xcol in [ (“Node size”, “Node size”), (“mtry”, “mtry”)]: subset = results[results[“Comparison”] == comparison]

plt.figure(figsize=(7, 4))
plt.plot(subset[xcol], subset["Squared bias"],
         marker="o", label="Squared bias")
plt.plot(subset[xcol], subset["Variance"],
         marker="o", label="Variance")
plt.xlabel(xcol)
plt.ylabel("Average across test points")
plt.title(f"Bias-variance trade-off: {comparison}")
plt.legend()
plt.grid(alpha=0.3)
plt.show()

Question 3: Planning a random-forest analysis skill

In earlier homework, some students wrote long skill files with detailed instructions, while others wrote short skills emphasizing their specific requirements or references. These approaches may perform differently depending on the AI and the task. A capable AI may already know standard ways to perform an analysis, so some instructions may be redundant, add little value, or sometimes make the analysis worse. It may be more useful to specify your personal choices for the analysis. An AI with more limited knowledge may benefit from detailed instructions that remind it of the steps to perform.

  1. Write one paragraph describing how you would write a skill that directs an AI to perform a random-forest analysis and produce a report for a future dataset. Discuss how you would balance standard analysis instructions with your personal preferences, considering the AI’s capabilities.

  2. Provide 10 instructions you would consider including in the skill, ordered from the most basic instructions to the more personal preferences. Your list may cover computation, tuning, tables, figures, interpretation, presentation, or other aspects of a random-forest report.

You only need to discuss how the skill should be written. You are not required to write a complete skill file or test it.

Question 3 Solution

I would write a random-forest analysis skill that provides clear instructions for the important steps while allowing the AI flexibility to adapt to different datasets. A capable AI likely already understands standard procedures such as splitting data, fitting models, and evaluating predictions, so I would avoid including excessive explanations of these steps. Instead, I would focus on specifying my personal preferences, such as using reproducible random seeds, selecting tuning parameters through cross-validation or OOB error, creating clear visualizations, and explaining results in simple language. For an AI with less statistical knowledge, I would include more detailed instructions to prevent mistakes such as using test data during tuning. Overall, I would want the skill to be detailed enough to ensure accurate and consistent analysis without restricting the AI’s ability to make appropriate decisions based on the dataset.

Identify the problem type: Determine whether the dataset requires regression or classification and identify the response and predictor variables.

Prepare the data: Check for missing values, incorrect variable types, and other data quality issues before fitting the model.

Separate training and test data: Use training data for model development and reserve the test set for final evaluation.

Fit a baseline random forest: Train an initial model using default settings to establish a benchmark.

Tune important parameters: Consider parameters such as mtry and node size, selecting appropriate candidate values based on the dataset.

Use appropriate model selection: Select tuning parameters using cross-validation or out-of-bag error without using the test set.

Evaluate model performance: Report relevant metrics, such as MSE for regression or misclassification rate and a confusion matrix for classification.

Analyze variable importance: Calculate variable importance when appropriate and explain which predictors contribute most to the model’s predictions.

Create clear tables and figures: Present tuning results and model performance using organized tables and labeled figures that are easy to interpret.

Write an understandable report: Explain the results in straightforward language, emphasize the bias-variance trade-off, discuss limitations, and conclude with the main findings rather than focusing only on technical output.
