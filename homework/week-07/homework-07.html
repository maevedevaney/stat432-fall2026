Question 1: LDA

Let's start by estimating the components of LDA. From the lecture notes, for each target point $\mathbf{x}_0$, we find the class label $k$ with the largest score

$$ \mathbf{x}_0^{\mathsf T}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_k -\frac12\boldsymbol{\mu}_k^{\mathsf T}\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_k +\log\pi_k. $$

Thus, we need to estimate:

  • the prior probabilities $\pi_k$;
  • the mean vector (centroid) $\boldsymbol{\mu}_k$ for each class; and
  • the pooled covariance matrix $\boldsymbol{\Sigma}$.

Use saheart.csv, the SAheart data from ElemStatLearn. The two classes are defined by chd, the coronary heart disease indicator. Question 1 Solution:

import numpy as np import pandas as pd

heart = pd.read_csv("data/saheart.csv") heart["famhist"] = heart["famhist"].map({ "Absent": 1, "Present": 2 })

X = heart.drop(columns="chd").to_numpy() y = heart["chd"].to_numpy()

n, p = X.shape classes = np.unique(y) K = len(classes)

Prior probabilities

priors = np.array([np.mean(y == k) for k in classes]) print("Prior probabilities:", priors)

Class means

means = np.array([X[y == k].mean(axis=0) for k in classes]) print("Class means:\n", means)

Pooled covariance matrix

S = np.zeros((p, p))

for k in classes: Xk = X[y == k] S += (len(Xk) - 1) * np.cov(Xk, rowvar=False)

S = S / (n - K)

print("Pooled covariance matrix:\n", S)

from sklearn.metrics import confusion_matrix

S_inv = np.linalg.inv(S)

Calculate LDA scores for each class

scores = np.column_stack([ X @ S_inv @ means[j] - 0.5 * means[j] @ S_inv @ means[j] + np.log(priors[j]) for j in range(K) ])

Predicted classes

pred_manual = classes[np.argmax(scores, axis=1)]

Confusion matrix

cm_manual = confusion_matrix(y, pred_manual, labels=classes) print("Manual LDA confusion matrix:\n", cm_manual)

Check dimensions

print("X:", X.shape) print("Means:", means.shape) print("Covariance:", S.shape) print("Scores:", scores.shape)

from sklearn.discriminant_analysis import LinearDiscriminantAnalysis

lda_model = LinearDiscriminantAnalysis( solver="svd", priors=priors )

lda_model.fit(X, y) pred_lda = lda_model.predict(X)

cm_lda = confusion_matrix(y, pred_lda, labels=classes)

print("Sklearn LDA confusion matrix:\n", cm_lda) print("Do predictions match?", np.array_equal(pred_manual, pred_lda))

from sklearn.discriminant_analysis import QuadraticDiscriminantAnalysis from sklearn.metrics import confusion_matrix

Load datasets

train = pd.read_csv("data/zip-train.csv.gz", header=None) test = pd.read_csv("data/zip-test.csv.gz", header=None)

X_train = train.iloc[:, 1:].to_numpy() X_test = test.iloc[:, 1:].to_numpy()

Calculate pixel variances from training data

pixel_vars = np.var(X_train, axis=0, ddof=1)

Select 40 pixels with highest variance

top40 = np.argsort(pixel_vars)[-40:][::-1]

X_train40 = X_train[:, top40] X_test40 = X_test[:, top40]

Fit QDA

qda40 = QuadraticDiscriminantAnalysis(tol=1e-8) qda40.fit(X_train40, y_train)

Misclassification rate

error40 = np.mean(pred40 != y_test) print("Test misclassification rate:", error40)

Question 3: Compare LDA and QDA

In this simulation, we will study how the relative performance of LDA and QDA changes with the true covariance structure. The parameter $\rho$ controls the distribution from which we generate the data; it is not a tuning parameter of LDA or QDA.

Consider a classification problem with two equally likely classes, labeled 1 and 2, and $p=10$ covariates. The first two covariates have the class-conditional distributions

$$ \begin{pmatrix}X_1\X_2\end{pmatrix}\mid Y=1 \sim N_2\left( \begin{pmatrix}-1\0\end{pmatrix}, \begin{pmatrix}1&\rho\\rho&1\end{pmatrix} \right), $$

$$ \begin{pmatrix}X_1\X_2\end{pmatrix}\mid Y=2 \sim N_2\left( \begin{pmatrix}1\0\end{pmatrix}, \begin{pmatrix}1&-\rho\-\rho&1\end{pmatrix} \right). $$

In both classes, the remaining eight covariates are independent standard normal variables, independent of the first two. Consider

$$ \rho\in{0,0.2,0.4,0.6,0.8,0.9}. $$

For each value of $\rho$, generate 100 training observations and 1,000 independent test observations from each class. Fit ordinary LDA and QDA using all 10 covariates and equal class priors. Estimate the class means from the training data, with one pooled covariance matrix for LDA and one full covariance matrix per class for QDA. Set a random seed and report it.

a. Generate one dataset for each value of $\rho$. Fit both methods and calculate their test misclassification rates. Within each setting, use the same training and test observations for the two methods.

b. At each fixed value of $\rho$, repeat the experiment 50 times, generating new training and test observations in each repetition. Plot average test error against $\rho$ in one figure, with one curve for LDA and one for QDA. These curves compare performance across different data-generating distributions.

c. Compare the two methods at small and large values of $\rho$. How does changing the true covariance structure affect their relative performance? Explain the pattern using their covariance assumptions and the bias-variance trade-off. How can the eight noise covariates affect performance even though they contain no information about the class label?

Question 3 Solution:

from sklearn.discriminant_analysis import ( LinearDiscriminantAnalysis, QuadraticDiscriminantAnalysis )

rng = np.random.default_rng(123) rho_values = [0, 0.2, 0.4, 0.6, 0.8, 0.9]

def generate_data(n_per_class, rho): mu1 = np.array([-1] + [0] * 9) mu2 = np.array([1] + [0] * 9)

Sigma1 = np.eye(10)
Sigma2 = np.eye(10)

Sigma1[0, 1] = Sigma1[1, 0] = rho
Sigma2[0, 1] = Sigma2[1, 0] = -rho

X1 = rng.multivariate_normal(mu1, Sigma1, n_per_class)
X2 = rng.multivariate_normal(mu2, Sigma2, n_per_class)

X = np.vstack((X1, X2))
y = np.array([1] * n_per_class + [2] * n_per_class)

return X, y

results_a = []

for rho in rho_values: X_train, y_train = generate_data(100, rho) X_test, y_test = generate_data(1000, rho)

lda = LinearDiscriminantAnalysis(
    priors=[0.5, 0.5]
)
qda = QuadraticDiscriminantAnalysis(
    priors=[0.5, 0.5]
)

lda.fit(X_train, y_train)
qda.fit(X_train, y_train)

lda_error = np.mean(lda.predict(X_test) != y_test)
qda_error = np.mean(qda.predict(X_test) != y_test)

results_a.append([rho, lda_error, qda_error])

results_a = pd.DataFrame( results_a, columns=["rho", "LDA Error", "QDA Error"] )

print(results_a)

import matplotlib.pyplot as plt

rng = np.random.default_rng(123) n_rep = 50

results_b = []

for rho in rho_values: lda_errors = [] qda_errors = []

for j in range(n_rep):
    X_train, y_train = generate_data(100, rho)
    X_test, y_test = generate_data(1000, rho)

    lda = LinearDiscriminantAnalysis(
        priors=[0.5, 0.5]
    )
    qda = QuadraticDiscriminantAnalysis(
        priors=[0.5, 0.5]
    )

    lda.fit(X_train, y_train)
    qda.fit(X_train, y_train)

    lda_errors.append(
        np.mean(lda.predict(X_test) != y_test)
    )

    qda_errors.append(
        np.mean(qda.predict(X_test) != y_test)
    )

results_b.append([
    rho,
    np.mean(lda_errors),
    np.mean(qda_errors)
])

results_b = pd.DataFrame( results_b, columns=["rho", "LDA Error", "QDA Error"] )

print(results_b)

Plot

plt.plot( results_b["rho"], results_b["LDA Error"], marker="o", label="LDA" )

plt.plot( results_b["rho"], results_b["QDA Error"], marker="s", label="QDA" )

plt.xlabel("Rho") plt.ylabel("Average Test Misclassification Rate") plt.title("LDA vs QDA Test Error") plt.legend() plt.grid(True) plt.show()

part c: When (\rho) is small, LDA generally performs better because the two classes have similar covariance matrices. Since LDA assumes equal covariance matrices, it estimates fewer parameters and has lower variance. As (\rho) increases, the covariance matrices become more different. QDA can account for these differences because it estimates a separate covariance matrix for each class. Therefore, QDA may outperform LDA at larger values of (\rho). This illustrates the bias-variance trade-off. LDA has lower variance but can have higher bias when the covariance matrices differ, while QDA is more flexible but has higher estimation variance. The eight noise predictors can worsen performance because both models must estimate additional parameters, even though these predictors contain no useful classification information.
