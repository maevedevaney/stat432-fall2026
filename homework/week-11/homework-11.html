Question 1: Implementing K-means

K-means is a relatively simple algorithm that we can write ourselves. For Questions 1 and 2, do not use an existing function that performs K-means directly.

Generate 10 observations with two independent standard normal coordinates. Set a random seed and report it. Randomly assign the observations to K=2K=2 clusters, making sure neither cluster is empty. Let C(i)C(i) denote the cluster assigned to observation xix_i, and let mkm_k denote the mean of cluster kk.

  1. Perform one iteration: calculate the cluster means, then assign each observation to its closest mean using Euclidean distance. Report the means and updated assignments, and plot the observations colored by their updated assignments.

  2. Write a function that repeats these two steps until the assignments stop changing or a specified maximum number of iterations is reached. Your function should work for a data matrix with any number of variables and a chosen number of clusters KK. Start from a nonempty assignment to each cluster; if a cluster becomes empty during iteration, keep its previous mean. Recalculate the cluster means from the final assignments before returning them. Return the final assignments, cluster means, and within-cluster sum of squares,

    ∑k=1K∑i:C(i)=k‖xi−mk‖2. \sum_{k=1}^K\sum_{i:\,C(i)=k}\lVert x_i-m_k\rVert^2.

  3. Apply your function to the same 10 observations from two different random initial assignments. Report the final plots, cluster means, and within-cluster sums of squares. Do the two runs produce the same grouping and objective value? Explain your findings.

SEED = 1234

part a

rng = np.random.default_rng(SEED)
X = rng.standard_normal((10, 2))

def random_nonempty_labels(n, K, rng):
    if not 1 <= K <= n:
        raise ValueError("K must be between 1 and the number of observations")
    labels = np.concatenate((np.arange(K), rng.integers(K, size=n-K)))
    rng.shuffle(labels)
    return labels

def cluster_means(X, labels, K, old_means=None):
    means = np.zeros((K, X.shape[1]), dtype=float) if old_means is None else old_means.copy()
    for k in range(K):
        members = X[labels == k]
        if len(members) > 0:
            means[k] = members.mean(axis=0)
    return means

def closest_means(X, means):
    # Squared Euclidean distance has the same minimizing center as distance.
    d2 = ((X[:, None, :] - means[None, :, :]) ** 2).sum(axis=2)
    return np.argmin(d2, axis=1)

initial = random_nonempty_labels(len(X), 2, rng)
initial_means = cluster_means(X, initial, 2)
updated = closest_means(X, initial_means)
print("Initial assignments (clusters numbered 1 and 2):", initial + 1)
print("Means before reassignment (rows = clusters):\n", initial_means)
print("Updated assignments:", updated + 1)
print(pd.DataFrame({'x1': X[:, 0], 'x2': X[:, 1], 'initial_cluster': initial+1,
                    'updated_cluster': updated+1}).round(3).to_string(index=False))
plt.figure(figsize=(6, 5))
plt.scatter(X[:, 0], X[:, 1], c=updated, cmap='coolwarm', s=85, edgecolor='black')
plt.scatter(initial_means[:, 0], initial_means[:, 1], marker='X', s=180, c=['navy', 'darkred'], edgecolor='white')
for i, (x, y) in enumerate(X):
    plt.annotate(str(i+1), (x, y), xytext=(5, 5), textcoords='offset points')
plt.title('Question 1(a): assignments after one iteration')
plt.xlabel('x1'); plt.ylabel('x2'); plt.grid(alpha=.2); plt.show()

part b


def my_kmeans(X, K, initial_labels=None, max_iter=100, seed=4321):
    X = np.asarray(X, dtype=float)
    if X.ndim != 2 or not np.isfinite(X).all():
        raise ValueError('X must be a finite two-dimensional numerical matrix')
    n, p = X.shape
    if not 1 <= K <= n or max_iter < 1:
        raise ValueError('Require 1 <= K <= n and max_iter >= 1')
    if initial_labels is None:
        initial_labels = random_nonempty_labels(n, K, np.random.default_rng(seed))
    labels = np.asarray(initial_labels, dtype=int).copy()
    if labels.shape != (n,) or set(labels.tolist()) != set(range(K)):
        raise ValueError('Initial labels must use all cluster indices 0,...,K-1')
    means = cluster_means(X, labels, K)
    for iteration in range(1, max_iter+1):
        new_labels = closest_means(X, means)
        if np.array_equal(new_labels, labels):
            break
        labels = new_labels
        means = cluster_means(X, labels, K, old_means=means)
    # Means correspond to the final labels, including when max_iter is reached.
    means = cluster_means(X, labels, K, old_means=means)
    wcss = float(np.sum((X - means[labels]) ** 2))
    return labels, means, wcss

The two runs produce different groupings and different objective values: Run 1 has WCSS 8.6381, while Run 2 has WCSS 11.4965. Run 1 is better by the WCSS criterion. K-means minimizes WCSS locally, so different starting assignments can lead to different local solutions. Cluster labels themselves are arbitrary, so a simple swap of labels 1 and 2 does not count as a different grouping.

csv_path = Path('data/mtcars.csv')
if not csv_path.exists():

cars = pd.read_csv(csv_path)
car_names = cars['car'].tolist()
features = cars.drop(columns=['car'])
Z = (features - features.mean()) / features.std(ddof=1)
distances = pdist(Z.to_numpy(), metric='euclidean')
methods = ['single', 'complete', 'average']
linkages = {method: linkage(distances, method=method) for method in methods}

Cluster 1 (15 cars) is the lighter, more fuel-efficient group: mean mpg = 24.65, wt = 2.58, and hp = 91.33. Cluster 2 (12 cars) contains heavier eight-cylinder, automatic-transmission cars, with mean mpg = 15.05, wt = 4.10, and disp = 357.62. Complete linkage and three clusters give a useful separation of these distinct profiles, visible in the dendrogram and supported by the original-scale means.

Why standardize? Without standardization, large-scale variables such as displacement (disp) and horsepower (hp) can dominate Euclidean distances over variables such as weight (wt) and transmission (am). Standardizing gives each variable unit sample variance, so each has a more comparable numerical influence. This is a modeling choice: correlated variables can still receive overlapping influence, and standardization does not make binary and continuous variables identical in meaning.
